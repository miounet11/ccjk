# packages/ 历史归档说明

**状态**：已废弃（Archived）

## 背景

在 ccjk v14 及更早版本（2025 年中），项目曾尝试构建更宏大的 AI 编码基础设施，包括：

- `ccjk-daemon`：后台守护进程、进程管理、Claude 拦截
- `ccjk-server`：远程控制服务器、认证、会话同步
- `ccjk-app`：React Native / Expo 移动端伴侣应用
- `ccjk-evolution`：进化层 / 自我改进相关实验
- `ccjk-telegram-bot`：Telegram 远程交互入口
- `ccjk-wire`：跨进程 / 跨设备通信协议

这些尝试对应当时的“云同步、远程控制、brain、sandbox”等功能方向。

## 2026 年 v15 重构决定

v15 系列（2026-05）进行了**一次彻底的战略收缩**：

- 从“大而全的 AI Agent 平台”回归到**专注的本地配置 CLI**。
- 明确产品边界：“只做配置工具，不主动写代码、不装 hooks、不开后台进程”。
- 所有上述实验性子项目停止维护，代码不再更新。

**当前主仓库只维护根目录下的 `src/` CLI 逻辑**。

## 后续处理建议

- 这些目录仅保留历史参考价值。
- 如需恢复其中任何功能，请从 git 历史单独提取到独立仓库（推荐）。
- **不要**在这些目录下新增代码或依赖。
- 未来若有类似远程/守护需求，应作为独立项目（例如 `ccjk-remote`）重新设计，而非复活旧架构。

**维护者注（2026-05）**：本次清理是 v15 “极致简单 + 外科手术”原则的体现。仓库现在名实相符，只做 Clavue / Claude Code / Codex / Grok 的专业配置层。

## 额外说明：dist/ 历史体积

`dist/chunks/`（约 4.2MB，143 个文件）及多个旧 `index*.mjs` 是 v15 重写前多次实验性构建的遗留产物（曾有 15+ 次“从零重写”尝试）。当前 `dist/cli.js` 等活跃产物体积很小。

- `.gitignore` 已包含 `dist`，但历史提交已携带这些文件。
- 未来如需彻底清理仓库体积，可在独立 PR 中使用 `git filter-repo` 或 BFG 工具（需团队共识）。
- 日常开发请优先使用 `pnpm dev`（tsx 直跑 src），避免依赖陈旧的 dist 产物。

相关讨论见根目录 `ARCHITECTURE.md` 和 `PRODUCT.md`。
