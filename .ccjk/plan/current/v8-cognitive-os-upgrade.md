 # 策略执行器（3个文件）\n└── .ccjk/\n    ├── context/              # 生成的上下文\n    ├── index/                # 文档索引\n    ├── docs/                 # 本地文档\n    └── reports/              # 本地报告\n```\n\n### 数据模型\n\n#### Eval Scenario Schema\n```typescript\ninterface EvalScenario {\n  id: string\n  suite: string\n  description: string\n  command: string\n  runs?: number\n  assertions: EvalAssertion[]\n  metrics?: string[]\n}\n\ninterface EvalAssertion {\n  type: 'exit_code' | 'file_exists' | 'contains_text' | 'json_field' | 'threshold'\n  expected?: number | string | boolean\n  path?: string\n  value?: string\n  field?: string\n  operator?: 'eq' | 'gte' | 'lte'\n}\n```\n\n#### Context Pack Schema\n```typescript\ninterface ContextPack {\n  projectIdentity: string\n  stack: StackInfo\n
