## 📐 CCJK 2.0 六大核心升级

### 1️⃣ Hook 强制认知机制
- **L1/L2/L3 三级强制 Hook**
- **Skills 触发率**: 30% → 90%+
- **核心价值**: 强制 AI 执行认知流程，不再依赖"运气"

### 2️⃣ 三层追溯框架
- **L1（表面错误）→ L2（设计模式）→ L3（领域约束）**
- **自动追溯**: 从配置错误到平台约束到设计决策
- **核心价值**: 解决根本问题，而非表面症状

### 3️⃣ 动态 Workflows 系统
- **AI 驱动生成**: 从模板库到实时生成
- **生成时间**: <10s
- **50+ 片段库**: 可复用的工作流构建块

### 4️⃣ Agents 网络重构
- **通信总线**: <100ms 延迟
- **专业技能系统**: 每个 Agent 有明确的专业领域
- **协作协议**: 请求-响应、协商、投票、学习

### 5️⃣ Cloud Skills 2.0
- **智能预处理**: 验证、优化、安全扫描
- **技能市场**: 搜索、推荐、评分、社区协作
- **版本管理**: 语义化版本、自动更新、一键回滚

### 6️⃣ CCJK-Actionbook MCP
- **信息预计算**: AST、符号、调用图
- **查询速度**: <10ms（vs >1s 运行时）
- **增量索引**: 只更新变更的文件

## 🔧 技术栈

### 核心框架
- TypeScript 5.9+（ESNext，严格模式）
- Node.js 20+（ESM 模块）
- Anthropic Claude API（Sonnet/Opus/Haiku）
- CAC（CLI 框架）
- i18next（国际化）

### 新增技术
- **背景 Agent 管理**: Worker Threads / Child Processes
- **缓存层**: Redis（本地开发用内存缓存）
- **MCP 服务器**: 自定义 Actionbook MCP
- **AI 生成**: Anthropic API（工作流生成）
- **信息预计算**: AST 分析、符号解析、图算法

### 基础设施
- **CI/CD**: GitHub Actions
- **测试**: Vitest（单元、集成、E2E）
- **文档**: VitePress
- **云存储**: GitHub Gist（初期）/ 自建后端（后期）
