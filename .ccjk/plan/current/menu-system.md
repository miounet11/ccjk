## 📋 概述

### 功能目标

创建一个用户友好的交互式菜单系统，将 CCJK 的全部功能整合到统一的菜单界面中，让用户能够：

1. **一键配置 API** - 核心卖点，最简单的方式配置 Claude API
2. **发现所有功能** - 清晰展示已整合的全部功能
3. **零配置体验** - 保持 zero-config 的设计理念
4. **完美使用体验** - 达到 Claude Code CLI 的最佳使用体验

### 预期价值

- **降低学习曲线** - 新用户无需记忆命令即可使用
- **提高功能发现率** - 用户能看到并使用更多功能
- **简化 API 配置** - 一键完成复杂的 API 配置流程
- **增强用户粘性** - 更好的体验带来更高的使用率

### 影响范围

- 新增 `src/menu/` 模块
- 修改 CLI 入口逻辑
- 集成现有命令模块
- 更新帮助文档

## 📐 技术方案

### 架构设计

```
src/menu/
├── index.ts                 # 模块入口
├── types.ts                 # 类型定义
├── menu-engine.ts           # 菜单引擎核心
├── menu-renderer.ts         # 菜单渲染器
├── menu-config.ts           # 菜单配置
├── components/
│   ├── status-bar.ts        # 状态栏组件
│   ├── breadcrumb.ts        # 面包屑导航
│   └── help-panel.ts        # 帮助面板
├── adapters/
│   ├── api-adapter.ts       # API 配置适配器（核心）
│   ├── skills-adapter.ts    # Skills 适配器
│   ├── mcp-adapter.ts       # MCP 适配器
│   ├── agents-adapter.ts    # Agents 适配器
│   ├── session-adapter.ts   # Session 适配器
│   ├── context-adapter.ts   # Context 适配器
│   └── hooks-adapter.ts     # Hooks 适配器
└── utils/
    ├── shortcuts.ts         # 快捷键处理
    ├── search.ts            # 搜索功能
    └── i18n.ts              # 国际化支持
```

### 数据模型

```typescript
// 菜单项定义
interface MenuItem {
  id: string
  label: string
  description?: string
  icon?: string
  shortcut?: string
  action?: MenuAction
  submenu?: MenuItem[]
  condition?: () => boolean | Promise<boolean>
  badge?: () => string | null  // 状态徽章
  priority?: 'core' | 'feature' | 'setting'
}

// 菜单动作
interface MenuAction {
  type: 'command' | 'function' | 'submenu' | 'external'
  handler: string | (() => Promise<void>)
  options?: Record<string, unknown>
}

// 菜单状态
interface MenuState {
  currentPath: string[]      // 当前路径（面包屑）
  history: string[][]        // 导航历史
  searchQuery?: string       // 搜索查询
  projectInfo?: ProjectInfo  // 项目信息（按需加载）
}
```

### API 设计

```typescript
// 菜单引擎 API
class MenuEngine {
  // 启动菜单
  async start(): Promise<void>

  // 导航到指定菜单
  async navigate(path: string[]): Promise<void>

  // 返回上级
  async back(): Promise<void>

  // 执行搜索
  async search(query: string): Promise<MenuItem[]>

  // 刷新项目信息
  async refreshProjectInfo(): Promise<void>

  // 退出菜单
  async exit(): Promise<void>
}
```
