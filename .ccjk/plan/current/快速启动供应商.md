# 功能规划：快速启动供应商 (Quick Provider Launch)

## 📋 概述

### 功能目标
实现 `npx ccjk <provider-shortcode>` 快速启动功能，让用户通过简短的供应商代码快速配置 API 服务，无需进入完整菜单流程。

### 预期价值
- **用户体验提升**: 从 5+ 步操作简化为 1 条命令
- **降低使用门槛**: 新用户可通过分享的短码快速上手
- **社区生态**: 支持用户自建供应商短码，形成共享生态

### 影响范围
- CLI 入口层 (`src/cli.ts`, `src/cli-lazy.ts`)
- 新增快速启动命令模块
- 云服务端 API（新增供应商注册表服务）
- 现有 API 配置流程复用

### 2. 云服务端 API 设计

**基础 URL**: `https://api.claudehome.cn/v1`

#### API 端点

| 方法 | 端点 | 描述 |
|------|------|------|
| GET | `/providers/{shortcode}` | 查询供应商信息 |
| POST | `/providers` | 创建新供应商 |
| GET | `/providers` | 列出所有供应商（可选） |

#### 数据模型

```typescript
// 供应商注册表
interface ProviderRegistry {
  shortcode: string      // 唯一短码，如 "302", "bltcy"
  name: string           // 显示名称，如 "302.AI"
  apiUrl: string         // API 基础 URL
  description?: string   // 描述信息
  models?: string[]      // 推荐模型列表
  createdAt: string      // 创建时间
  createdBy?: string     // 创建者（可选）
  verified: boolean      // 是否官方验证
}
```

#### API 响应格式

**GET /providers/{shortcode}** - 查询供应商

```json
// 成功 (200)
{
  "success": true,
  "data": {
    "shortcode": "302",
    "name": "302.AI",
    "apiUrl": "https://api.302.ai",
    "description": "302.AI 中转服务",
    "models": ["gpt-4", "gpt-3.5-turbo", "claude-3-opus"],
    "verified": true
  }
}

// 未找到 (404)
{
  "success": false,
  "error": {
    "code": "PROVIDER_NOT_FOUND",
    "message": "Provider 'bltcy' not found"
  }
}
```

**POST /providers** - 创建供应商

```json
// 请求体
{
  "shortcode": "bltcy",
  "name": "BLTCY Service",
  "apiUrl": "https://api.bltcy.com/v1"
}

// 成功 (201)
{
  "success": true,
  "data": {
    "shortcode": "bltcy",
    "name": "BLTCY Service",
    "apiUrl": "https://api.bltcy.com/v1",
    "verified": false,
    "createdAt": "2026-01-25T10:30:00Z"
  }
}

// 短码已存在 (409)
{
  "success": false,
  "error": {
    "code": "SHORTCODE_EXISTS",
    "message": "Shortcode 'bltcy' already exists"
  }
}
```

## 🗄️ 云服务端开发需求

### 技术栈建议

| 组件 | 推荐方案 | 备选方案 |
|------|----------|----------|
| 运行时 | Cloudflare Workers | Vercel Edge |
| 数据库 | Cloudflare D1 (SQLite) | PlanetScale |
| 缓存 | Cloudflare KV | Redis |

### 数据库 Schema

```sql
CREATE TABLE providers (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  shortcode TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  api_url TEXT NOT NULL,
  description TEXT,
  models TEXT,  -- JSON array
  verified BOOLEAN DEFAULT FALSE,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  created_by TEXT,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_shortcode ON providers(shortcode);
```

### API 安全考虑

1. **Rate Limiting**: 每 IP 每分钟 60 次请求
2. **短码验证**:
   - 长度: 2-20 字符
   - 格式: 仅允许小写字母、数字、连字符
   - 保留词: 禁止使用 `help`, `menu`, `setup` 等
3. **URL 验证**: 必须是有效的 HTTPS URL
4. **防滥用**: 同一 IP 每天最多创建 5 个供应商
